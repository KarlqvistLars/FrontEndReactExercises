## Quick start React/Vite project

Kör 
```
"npm create vite@latest my-app -- --template react-ts" 
```
foldern namnges 'my-appp' med root foldern.
Sen kan man städa lite innan första commit
 
public folder kan tömmas.
(behåll eller byt ut favicon)
 
app.css kan raderas.
 
app.tsx/jsx kan rensas.
 
index.css kan rensas sedan ha global css.
 
assets folder kan rensas.
 
readme radera o skriv någon egen rad
